# 关卡编辑器错误类型与含义表

## 适用范围

面向关卡开发者与 agent，说明编辑器检查结果、提示文案及常见操作错误。语言目标为《Turing Complete》Windows 2.1.334；编辑器自身规则随版本变化。适用于打包程序的使用与关卡排错。

配套文档：[Simplex 语言规范](simplex-language-spec.md)、[游戏关卡语法参考](simplex-game-level-reference.md)。

## 诊断模型与处理顺序

1. 修复工程读取、电路解析和宿主上下文错误。
2. 修复词法与语法错误，再处理作用域、类型、控制流和绑定问题。
3. 调用原版编译器确认代码与宿主声明匹配。
4. 在游戏中验证周期行为和判题结果。编译成功不等于关卡通过。

**错误码**用于识别具体诊断；**检查状态**表示一次检查的整体结果；**异常类型**标识发生错误的操作类别。三者不可互换。表中的“{…}”表示动态名称、类型或位置，不是要求原样输入的文本。

agent 应优先使用检查面板或导出报告中可获得的错误码、严重程度、文件与节点定位信息，不从翻译后的提示猜测错误码。没有稳定错误码的文案只用于解释，不应作为程序分支条件。

## 检查状态

| 状态 | 含义 | 推荐处理 |
| --- | --- | --- |
| ok | 当前检查阶段成功 | 查看检查覆盖层次，再执行游戏验证 |
| unsupported | 编辑器检查入口拒绝当前功能，例如跨文件 import | 改用已支持形式；不要据此推断所有语言构造都不支持 |
| compiler_missing | 未找到原版编译器文件 | 配置有效的游戏安装目录 |
| compiler_unavailable | 原版编译器加载或初始化失败 | 查看附带诊断，检查平台与依赖 |
| host_unavailable | 电路、接口或生成宿主上下文不可用 | 修复端口定义、继承引用或宿主声明 |
| compile_error | 原版编译器拒绝源码 | 按映射后的源码位置修复；上下文异常时先检查宿主 |
| compiler_crash | 编译进程异常退出或未返回有效诊断 | 保留源码与日志，缩减复现；不要当作普通语法错误 |
| timeout | 编译检查超过时限 | 缩减输入并检查异常展开或编译器问题 |
| runtime_incompatible | 命中编辑器的运行环境兼容性检查 | 按具体诊断修改，不等同于语法错误 |

检查结果还可能带 editor_syntax、runtime_compatibility、typed_host 或 unavailable 等覆盖标记；它们不是错误码。定位无法映射时，编辑器可能回退到第 1 行，不能据此认定错误必在第一行。

## 蓝图诊断的修复映射

| 类型 | 推荐修复 |
| --- | --- |
| TYPE_MISMATCH | 对齐端口类型；插入数值转换节点，避免把整数直接连到 Bool |
| INVALID_CONSTANT | 检查位宽范围、除数和移位数量 |
| MISSING_BINDING / CONTEXT_ERROR | 重新选择电路端口或 UI 控件；核对方向与位宽 |
| MISSING_INPUT | 补接数据线或填写必需常量 |
| DATA_CYCLE | 移除表达式环；不要把组合图当成时序存储 |
| UNDECLARED_LOCAL / UNINITIALIZED_LOCAL | 在可见作用域声明，并确保所有到达路径已赋值 |
| MISSING_RETURN | 为所有执行分支补返回或合法合流 |
| INVALID_MERGE | 重新配对分支与合流点 |
| ILLEGAL_EFFECT | 将 UI 修改或错误设置移入允许的检查输出图 |
| UNUSED_NODE | 未使用节点不会生成代码；这是 warning，不必作为阻断错误处理 |

蓝图限制属于编辑器支持范围。例如输入图禁止 UI 副作用，不等于原版语言禁止函数调用 UI。

## 逻辑编辑校验（无独立稳定错误码）

| 文案或类型 | 含义 | 修复 |
| --- | --- | --- |
| 局部变量不在当前块作用域内，或在声明前使用 | 当前使用位置无法访问绑定 | 移动声明或调整节点所在块 |
| 绑定的局部变量不存在 | 变量被删除或引用失效 | 重新选择变量 |
| 不可变绑定不能重新赋值 | 写入 let 等只读绑定 | 需要修改时使用 var |
| 赋值目标必须可写 | 对字面量或函数结果赋值 | 改成变量、可写成员或下标 |
| default 分支重复 | 同一 switch 有多个默认分支 | 仅保留一个 default |
| switch 分支值重复 | case 表达式重复 | 合并或修改分支 |
| 读取 cycle 需要 cycle: Int 参数 | 当前函数缺少相应参数 | 修正函数签名或移除读取 |
| 读取 input/output 需要匹配参数 | 当前上下文不提供目标对象 | 使用对应回调参数 |
| break/continue 必须位于循环体内 | 控制语句所在位置不合法 | 移入循环或调整控制流 |

## 电路、资源与工程操作

| 异常类型或提示 | 含义 | 修复 |
| --- | --- | --- |
| CircuitError：元件不存在／导线不存在 | 对象已删除或引用过期 | 刷新选择并重新绑定 |
| 引脚位宽不匹配 | 两端位宽不同 | 调整位宽或使用合适的转换元件 |
| 端口位宽必须为 1–64 | 超出编辑器端口支持范围 | 使用允许位宽；不据此限制语言整数类型 |
| 引脚几何不可用／不支持创建 | 编辑器未掌握元件定义 | 使用支持的元件，保留原始资源 |
| 导线路径没有连接两个引脚 | 路径起终点与引脚不一致 | 重新布线 |
| 无可用引脚出口／无法绕开元件 | 引脚重叠、障碍或边界阻断布线 | 调整元件与导线位置或手工布线 |
| CodecError：空文件／数据截断／记录数量无效 | 电路二进制结构不完整 | 从有效副本恢复，不手工猜测缺失字节 |
| Snappy 长度或回引错误 | 压缩数据损坏或不符合格式 | 恢复有效电路文件 |
| 尚不支持电路版本／末尾有未识别数据 | 无法完整解码当前格式 | 使用兼容版本工具并保留原文件 |
| 坐标或字段超出保存范围 | 数据无法按原版格式编码 | 缩小坐标或修正字段值 |
| ParseError 或配置解析提示 | meta.txt 值、分隔符或括号不合法 | 按具体位置修复；配置格式不等同 Simplex |
| ProjectError：外部修改冲突 | 磁盘内容与编辑缓冲不一致 | 保留双方版本，重新载入或合并 |
| test.si 有未保存修改 | 切换蓝图来源可能覆盖缓冲 | 保存或保留副本后再切换 |
| 启用蓝图会接管 test.si | 需要处理来源切换与备份 | 按编辑器来源切换流程操作 |
| 预览后电路发生变化 | 复制依据的快照已过期 | 刷新预览后再复制 |

## 原版编译器诊断的解释边界

| 原版信息示例 | 含义与处理 |
| --- | --- |
| Variable … not in scope | 名称不在作用域，或使用了不支持的语言写法 |
| Variable not mutable | 对只读绑定赋值；检查 var/let 和引用参数 |
| … operator not declared … | 当前操作数类型没有匹配操作符；字段复合赋值还可能命中版本问题 |
| var declarations use '=' | 变量声明错误；使用 `var value = Int 0` |
| tok_unknown | 词法无法识别；检查 Tab、分号和特殊字符 |
| AssertionDefect / TODO | 编译器内部断言或未实现路径；保留最小复现，不将其解释为稳定语言诊断 |

## agent 处理协议

记录程序显示的检查阶段、错误码或状态、严重程度、关卡名称、行列或节点端口及完整消息；未显示的字段无需补造。面向用户或共享报告时移除绝对路径、用户名与运行时地址。

优先修复根因后重跑；不要自动改写不相关源码。遇到编译崩溃、外部冲突或未知电路格式时保留原始内容。没有有效诊断或因环境缺失跳过检查，均不得报告“验证通过”。
